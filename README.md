# 수호&지호 가족대시보드

수호(8세·초1)·지호(6세·어린이집) 가족을 위한 한 페이지 가족 대시보드입니다.

- **홈** — 맨 위에 두 아이의 포켓몬 프로필 카드(키·몸무게 포함), 그 아래 달력·D-Day·다가오는 일정·부산 해운대구 날씨·이거 사주세요·오늘 한눈에
- **일정** — 가족캘린더(월간) · 학원일정(주간) · 학교시간표(주간) — 학원·시간표는 수호·지호를 **나란히** 놓고 볼 수 있어요
- **할일** — 퀘스트·숙제·루틴 체크, 포켓몬 레벨/XP, 151 도감, 올클리어 알 부화
- **일기** — 가족 일기(사진 첨부·압축 저장, 검색)
- **학교생활** — 장산초등학교 공지·학사일정(하이클래스 기준), 가정통신문/준비물, 학교급식
- **성장·건강** — 키·몸무게·BMI 기록과 2017 소아청소년 성장도표(남아) 백분위·성장 곡선, 예방접종·건강검진 체크리스트
- **날씨** — 오늘/내일, 습도·미세먼지·초미세먼지·강수확률·풍속·자외선·일출/일몰, 시간별·주간 예보, 옷차림 추천, 네이버 날씨 바로가기
- **영상통화** — 역할(아빠·엄마·태블릿·아이들)과 방 코드만 맞추면 가족 기기끼리 영상통화 + 채팅
- **설정** — 가족/포켓몬 설정, 기기 동기화, JSON 백업·복원, 초기화

## 쓰는 법

1. 휴대폰/태블릿 Chrome에서 아래 주소를 엽니다.
   - https://soohojiho.github.io/
2. Chrome 메뉴 → **홈 화면에 추가** 를 누르면 앱처럼 전체화면으로 실행됩니다.

## 수호·지호 나란히 보기

- 일정 → **학원일정**: 기본이 `나란히`라서 왼쪽에 김수호, 오른쪽에 김지호 주간표가 나옵니다. `합쳐서`를 누르면 온 가족 학원을 한 표에 모아 봅니다. 엄마·아빠 학원은 나란히 화면 아래 `기타` 줄에 나옵니다.
- 일정 → **학교시간표**: 기본이 `나란히`입니다. `김수호` / `김지호`를 누르면 한 사람만 크게 볼 수 있습니다.
- 맨 위 `보기` 필터에서 한 사람(예: 김지호)을 고르면 그 사람 표만 나옵니다.
- 좁은 휴대폰 화면에서는 두 표가 위아래로 쌓입니다. 표의 수업/칸을 누르면 수정·삭제할 수 있어요.

## 키 · 몸무게 기록

홈 맨 위 아이 카드의 `📏` 배지를 누르면 키(cm)·몸무게(kg)와 잰 날짜를 적을 수 있습니다.
기록은 날짜별로 쌓여서 카드에 최신 값이 표시되고, 배지를 다시 누르면 이전 기록을 보고 지울 수 있습니다.

## 성장·건강 (성장 기록 · 예방접종·검진)

- `성장 기록`은 키·몸무게·BMI 최신 값과 이전 대비 변화, **또래 백분위**를 보여줍니다.
- 그래프는 **2017 소아청소년 성장도표(질병관리청·대한소아청소년과학회, 남아)** 의 3·50·97백분위 곡선 위에 우리 아이 측정값을 그립니다. `키`·`몸무게`·`BMI` 탭으로 바꿔 볼 수 있고, 측정 내역의 줄을 누르면 그 점이 그래프에 표시됩니다.
- 백분위는 성장도표의 L·M·S 값으로 계산합니다. **생년월일을 넣으면 개월 수가 정확해지고**, 넣지 않으면 카드의 만 나이로 추정합니다.
- `예방접종·검진`은 질병관리청 표준예방접종일정과 영유아 건강검진·학생 건강검진 시기를 아이 나이에 맞춰 보여주고, 받은 날짜와 함께 체크해 둘 수 있습니다.
- 참고용 기록입니다. 접종 여부는 예방접종도우미(nip.cdc.go.kr)에서 확인하고, 이상이 걱정되면 소아청소년과와 상담하세요.

## 영상통화

1. `영상통화` → **이 기기는 누구인가요?** 에서 역할(아빠·엄마·태블릿·아이들)을 고릅니다.
2. 가족 방 코드(`soohojiho-family`)는 그대로 두면 됩니다. 바꾸면 가족 기기도 같은 코드로 맞춰 주세요.
3. `통화 시작`을 누르면 같은 방 코드를 쓰는 가족 기기와 연결되고, 오른쪽 채팅으로 메시지를 주고받습니다.
4. 화면·소리는 기기 사이에서만 오가고 서버에 저장되지 않습니다(PeerJS 공개 중계 서버 사용, 별도 서버 설치 없음).

## 학교 일정은 하이클래스 기준

학사일정·시간표는 **하이클래스에서 확인한 내용**만 보여줍니다. 나이스(NEIS)에서 자동으로 받아오던 학사일정·시간표는 실제 반 일정과 달라 제외했고, 시간표는 칸을 눌러 직접 고칠 수 있습니다.

## 여러 기기에서 함께 쓰기 (기기 동기화)

태블릿 · 엄마 폰 · 아빠 폰이 같은 기록을 보려면 **기기마다 한 번씩** 아래를 설정합니다.

1. 위쪽 `🔄` 배지(또는 설정 → 기기 동기화)를 누릅니다.
2. GitHub에서 Personal access token을 만듭니다.
   - 간편: https://github.com/settings/tokens/new?scopes=repo&description=Family%20Dashboard%20Sync → **repo** 권한 체크
   - 세밀하게: https://github.com/settings/personal-access-tokens/new → Only select repositories에서 **Family-board** 선택, Repository permissions → **Contents: Read and write**
3. 만든 토큰(`ghp_…` 또는 `github_pat_…`)을 복사해 붙여넣고 **토큰 저장하고 연결**을 누릅니다.
4. 나머지 기기에서도 같은 방법으로 한 번만 설정하면, 이후에는 자동으로 맞춰집니다.

- 저장 위치: 비공개 저장소 `soohojiho/Family-board`의 `dashboard-data.json`
- 데이터가 바뀌면 약 2~3초 뒤 자동으로 올라가고, 앱을 열거나 다시 볼 때 다른 기기의 최신 기록을 가져옵니다.
- 필요할 때는 **지금 가져오기 / 지금 올리기**를 직접 눌러도 됩니다.
- **토큰은 그 기기의 브라우저(localStorage)에만 저장**되며, 사이트 파일이나 GitHub 저장소에는 남지 않습니다.
- 인터넷이 없으면 이 기기에만 저장하고, 연결되면 자동으로 다시 맞춥니다.

## 데이터

모든 기록(일정·일기·퀘스트·도감·키·몸무게)은 **그 기기의 브라우저(localStorage)** 에 저장됩니다.
기기 동기화를 켜면 위의 비공개 GitHub 저장소에도 같은 내용이 보관됩니다.
설정 → **JSON 내보내기 / 불러오기 / JSON 복사**로 백업하거나 옮길 수 있습니다.

## 실시간 자료

- 급식·학사일정·시간표: [NEIS 교육정보 개방 포털](https://open.neis.go.kr) (장산초등학교)
- 날씨: [Open-Meteo](https://open-meteo.com) (부산 해운대구)
- 포켓몬 이미지: [PokeAPI sprites](https://github.com/PokeAPI/sprites)

네이버 날씨는 CORS 정책상 페이지에서 직접 호출할 수 없어, 같은 지역 실시간 날씨를 Open-Meteo로 받고 네이버 날씨로 이동하는 버튼을 제공합니다.
