⚙️통화 설정

이 기기는 누구인가요?

역할은 이 기기에만 저장돼서 폰·태블릿이 서로 역할을 덮어쓰지 않아요.
같은 역할을 두 기기에서 고르면 연결되지 않아요.

가족 방 코드

방 코드가 같으면 어느 기기든 서로 연결돼요. 다른 사람이 쓰지 않는 나만의 코드로 바꿔도 좋아요.
영상·채팅은 PeerJS 공개 중계 서버로 기기끼리 직접 연결되며, 별도 서버 설치가 필요 없습니다.

📞 수신 대기 꺼짐
이 앱이 열려 있으면 카메라·마이크 권한 없이도 가족의 영상통화를 받을 준비를 해 둬요. 걸려 오면 벨소리·진동·알림으로 알려 줘요.
